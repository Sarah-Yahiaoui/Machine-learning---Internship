# Machine-learning---Internship

Classification non supervisée de données de grande dimension avec Fisher-EM

Présentation

Ce dépôt regroupe les travaux réalisés dans le cadre de mon stage de M1 Mathématiques appliquées à l'ingénierie,
l'industrie et l'innovation (MApI3), portant sur l'analyse de données de grande dimension et la classification non supervisée.

L'objectif principal est d'étudier la structure des données et d'identifier des groupes homogènes à l'aide de méthodes statistiques de clustering.

Objectifs

Le projet porte notamment sur:
 La classification non supervisée;
 L'analyse de données de grande dimension;
 La modélisation dans un espace latent;
 Les modèles de mélanges gaussiens;
 La séléction du nombre de classes;
 L'analyse de la stabilité des classifications;

Méthodologie

La méthode principale utilisée est l'algorithme FisherEM, une méthode de classification basée sur des modèles de mélanges gaussiens et une projection dans un espace latent discriminant.
Différents nombres de classes et différents modèles de covariance sont testés afin d'étudier la structure des données.
Le critère ICL ( Integrated Completed Likelihood) est utilisé pour comparer les modèles et séléctionner une classification adaptée.

Prétraitement des données

Les principales étapes de prétraitement comprennent :
 Le nettoyage des données;
 La gestion des valeurs manquantes;
 La standarisation des variables;
 La construction des matrices de données;
 
Analyse des résultats
Les classifications obtenues sont étudiées à l'aide de différentes analyses statistiques et représentations graphiques permettant notamment d'observer:
 La séparation des groupes;
 La distribution des classes;
 La distribution des variables;
 Les relations entre les variables;
 La stabilité des classifications;
